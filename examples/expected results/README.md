# Online Resource 2: sample data

**Article:** SINEX TRF Studio: an open-source network diagnostic tool for SINEX solutions and terrestrial reference frames
**Journal:** GPS Solutions (GPS Toolbox)
**Authors:** Gerasimos M. Dossas, Dimitrios Ampatzidis
**Corresponding author:** D. Ampatzidis, dampatzi@ihu.gr

Contents:
- `COE08827.SNX` and `CRI23527.SNX`: the sample solutions used in the User Manual (Online Resource 1). The sources are CODE (Center for Orbit Determination in Europe, University of Bern) and IGN Costa Rica (SIRGAS).
- `Sample runs (macOS, v1.5.2)/`: the expected results for the two sample files (see the README inside).
